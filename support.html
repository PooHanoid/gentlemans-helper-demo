Gentleman's Helper

Русский · English · Конфиденциальность / Privacy

Поддержка

Что делает приложение

Gentleman's Helper — расширение Safari для iPhone и iPad, которое проходит онлайн-курсы в своём темпе по пакету вопросов: узнаёт вопрос на странице курса, отвечает на него из пакета, листает слайды и запускает видео уроков. В режиме подсказок помощник выбирает ответ, а подтверждаете вы; в автоматическом режиме он подтверждает и идёт дальше сам. Само приложение показывает шаги настройки.

В приложении нет вопросов и нет описаний курсов: и то и другое приходит в пакете — файле JSON с вопросами и ответами и описанием страниц курса, который загружают файлом или по ссылке. Нужен iPad с iPadOS 15.4 или новее. Интерфейс — на русском языке.

Настройка

Помощник работает в Safari. Чтобы он появился на странице курса:

  1. Включите расширение: Настройки → Приложения → Safari → Расширения (в iOS и iPadOS 15–17: Настройки → Safari → Расширения).
  2. Там же разрешите ему доступ к сайтам вашего курса: «Разрешить», а не «на один день» — иначе завтра помощник пропадёт со страницы.
  3. Откройте курс в Safari и нажмите значок расширения: на iPad — в адресной строке (или кнопку расширений рядом с ним; в iPadOS 15–17 — в меню «aA» адресной строки), на iPhone — кнопку меню страницы слева от адреса → Gentleman's Helper. Загрузите пакет курса: файлом или по ссылке.
  4. На странице курса появится кнопка «H» — это панель помощника. START запускает, STOP останавливает.

Файлом пакет загружают кнопкой «📤 Импорт JSON» на странице «📚 База вопросов» (её открывает кнопка в окне расширения), а пока пакета нет — и кнопкой «⬆️ Импортировать файл» в самом окне.

Попробовать на демо-курсе

  1. Сделайте шаги 1–2 для сайта poohanoid.github.io (или разрешите доступ, когда Safari спросит).
  2. Откройте демо-курс: https://poohanoid.github.io/gentlemans-helper-demo/. Ссылка на пакет есть и на его первом экране.
  3. Откройте окно расширения, вставьте в поле ссылку на пример пакета и нажмите «🔗 Загрузить по ссылке»: https://poohanoid.github.io/gentlemans-helper-demo/sample-pack.json Окно сообщит «Загружено: 3 вопроса, профилей: 1».
  4. Справа на странице курса появится круглая кнопка «H» (если нет — обновите страницу).
  5. Выберите режим «💡 Подсказки (рекомендуется)» или «🤖 Полный автомат» и нажмите «▶️ START».
  6. Помощник откроет курс, ответит на вопросы 1–3 и пролистает слайд; в режиме подсказок он выбирает ответ, а Confirm нажимаете вы. Вопроса 4 в пакете нет нарочно: панель скажет «Нет в базе» — ответьте сами, и помощник пойдёт дальше. В конце панель скажет «Курс завершён».

Паузы нарочные, чтобы работа шла в темпе человека: по умолчанию 5 с перед выбором ответа, 15–25 с перед Confirm и 10–15 с перед Next. Они меняются в «⚙️ Настройки».

Формат пакета

Пакет — файл JSON. Пример — пакет демо-курса целиком:

{
  "format": "gentlemans-helper-pack",
  "version": "2026-09-25",
  "profiles": [
    {
      "id": "demo-v1",
      "when": ["#player.gh-demo"],
      "marker": { "selector": ".screen .counter" },
      "markerDecides": true,
      "kind": {
        "selector": ".screen .counter + .kind",
        "values": [
          { "text": "^select$", "mode": "single" },
          { "text": "^true or false$", "mode": "single" },
          { "text": "^multiple choices$", "mode": "multi" }
        ]
      },
      "question": ".screen .stem",
      "options": ".screen li.option",
      "optionText": ".text",
      "optionLabel": ".label",
      "optionChecked": ".chosen, .correct, .wrong",
      "confirm": "button.action",
      "action": {
        "selector": "button.action",
        "pending": "^confirm$",
        "ended": "^next$"
      },
      "course": {
        "selector": "header h1",
        "strip": "^Sample course:\\s*"
      }
    }
  ],
  "questions": {
    "Office fire safety": {
      "What should you do first when you discover a small fire in the office?": "Raise the alarm",
      "Fire doors may be propped open during working hours.": "False",
      "Which of these belong in a first-aid kit?": "Plasters; Sterile dressings; Disposable gloves"
    }
  }
}

Вопросы

  • questions — категории (обычно курсы), в них вопросы с ответами: {"Категория": {"Вопрос": "Ответ"}}. Категория может делиться на разделы: {"Категория": {"Раздел": {"Вопрос": "Ответ"}}}.
  • Ответ — строка. Несколько правильных вариантов пишутся через «; ». Для вопроса со свободным ответом — текст, который нужно вписать.
  • Вопрос и ответ сравниваются со страницей слово в слово: регистр, знаки препинания и пробелы не важны, слова — важны. Похожий, но не тот же вопрос помощник только показывает и ничего не нажимает.
  • При загрузке ответы из файла заменяют сохранённые ответы на те же вопросы; остальные сохранённые вопросы остаются. Файл, в котором есть только категории с вопросами, без format и profiles, тоже принимается.

Профили

profiles — описания страниц курса селекторами CSS: помощник ничего не угадывает и работает только там, где применим профиль. Профиль с тем же id заменяет сохранённый. Шаблоны надписей — регулярные выражения в строках, без учёта регистра.

  • id — имя профиля. Обязательно.
  • when — селекторы; профиль применяется только на странице, где есть все они. Обязательно.
  • question, options — где текст вопроса и строки вариантов. Обязательны, если плеер задаёт вопросы.
  • optionText, optionLabel — текст варианта внутри строки и метка («a», «B.»), которую нужно отбросить.
  • optionChecked — как страница отмечает выбранный вариант: по нему помощник проверяет, что выбор принят.
  • marker, markerDecides — надпись страницы «это вопрос» (selector, по желанию text); с markerDecides: true экран без неё — не вопрос.
  • kind — где страница пишет тип вопроса (selector) и какие надписи (values[].text) каким режимам соответствуют: single — один вариант, multi — несколько, scale — шкала, text — свободный ответ (поле ввода — input, по умолчанию textarea). Тип, которого нет в списке, помощник оставляет вам.
  • action — кнопка вопроса и её надписи: pending — ответ ещё не подтверждён («Confirm»), ended — подтверждён («Next»).
  • next — элемент, которым страница ведёт дальше. Если он указан, помощник нажимает только его и только когда страница его показывает; если нет — ищет кнопку с надписью next, continue, start, begin или proceed (после Confirm, нажатого им самим, — next, continue, forward или proceed). Плеер без вопросов (презентация) описывается профилем без question и options и обязательно с next.
  • confirm — кнопка подтверждения; сейчас помощник нажимает Confirm по action, а без него — по надписи (confirm, submit, check, ok).
  • course — где плеер пишет название курса (selector) и какую приставку убрать (strip); это категория для ответов, взятых со страницы курса.
  • done — признак конца теста или курса (selector, по желанию text): там помощник останавливается.

Вопросы и ответы

Кнопка «H» не появляется

Проверьте, что расширение включено и сайту курса дан доступ («Разрешить», а не «на один день»); что пакет загружен — в окне расширения нет предупреждения о пакете; и что профиль пакета описывает именно этот плеер. После выдачи доступа обновите страницу. На странице, где курса нет, окно расширения пишет «⋯ Курс не найден на этой странице».

Окно расширения пишет «⋯ Страница не ответила»

Кнопка «H» на странице есть, а окно расширения до неё не достаёт. Управляйте с панели «H» или обновите страницу. Не помогло — закройте Safari и откройте снова: так бывает сразу после обновления приложения.

Панель пишет «Нет в базе»

Этого вопроса нет в пакете слово в слово. Ответьте сами и нажмите Confirm — дальше помощник продолжит. Вопрос можно добавить на странице «📚 База вопросов» («➕ Добавить вопрос»).

Панель пишет «Проверьте ответ»

В базе похожий, но не тот же вопрос, или сохранённый ответ не совпал ни с одним вариантом дословно. Помощник показывает ответ из базы и ничего не нажимает — решаете вы.

Чем отличаются режимы?

«💡 Подсказки»: помощник выбирает ответ, Confirm нажимаете вы; слайды, видео и Next после ответа — его. «🤖 Полный автомат»: он и подтверждает, и идёт дальше сам, в том числе на оцениваемых тестах.

Можно ли так проходить мой курс?

Это решают правила вашего курса. Проверьте их, прежде чем включать автоматический режим, особенно на оцениваемом тесте.

Что значит «ответ со страницы»?

Один конкретный плеер курсов держит правильные ответы в самой странице. На нём помощник берёт ответ оттуда — в том числе на вопросы, которых нет в пакете, — и сразу добавляет его в вашу базу на iPad.

Что он пишет в вопросы со свободным ответом?

Ответ из базы, а если вопроса там нет — текст из «⚙️ Настройки» («No» по умолчанию). Оставьте это поле пустым, чтобы писать такие ответы самим. Текст, который уже есть в поле, помощник не перезаписывает.

Видео не запускается, панель пишет «Ролик ждёт касания»

Safari на iPhone и iPad включает звук только после касания. Коснитесь страницы в любом месте — ролик запустится. Помощник не перематывает и не ускоряет видео на экране. Чтобы следующий ролик запустился без касания, он проигрывает беззвучный звук или предыдущий ролик — без звука и скрытым.

Панель пишет «Экран возвращается — решите сами»

После Next курс снова показывает тот же экран. Помощник один раз за каждый START перезагружает страницу курса; если не помогло, этот экран остаётся вам.

Панель пишет «Отметьте согласие сами»

Рядом с кнопкой есть галочка согласия. Такие галочки помощник не ставит никогда.

Как перенести или сохранить базу?

На странице «📚 База вопросов»: «📥 Экспорт JSON» и «📤 Импорт JSON»; «📄 Экспорт PDF» — для чтения, с главой на каждый курс.

Куда уходят мои данные? Как удалить всё?

Никуда: всё хранится на устройстве (подробнее — политика конфиденциальности). Чтобы удалить всё, удалите приложение Gentleman's Helper.

Support

What the app does

Gentleman's Helper is a Safari extension for iPhone and iPad that works through self-paced online courses with a question pack: it recognises the question on the course page, answers it from the pack, moves through slides and plays the lesson videos. In hint mode the helper selects the answer and you confirm it; in automatic mode it confirms and moves on by itself. The app itself shows the setup steps.

The app contains no questions and no course descriptions: both come in a pack — a JSON file with questions and answers and a description of the course pages — loaded from a file or a link. It needs an iPad with iPadOS 15.4 or later. The interface is in Russian; the labels below are quoted as they appear, with a translation.

Setup

The helper works in Safari. To have it appear on the course page:

  1. Turn the extension on: Settings → Apps → Safari → Extensions (on iOS and iPadOS 15–17: Settings → Safari → Extensions).
  2. In the same place, allow it access to your course’s websites: “Allow” (“Always Allow” when Safari asks), not “Allow for One Day” — otherwise the helper will be gone from the page tomorrow.
  3. Open the course in Safari and tap the extension’s icon: on iPad in the address bar (or the extensions button next to it; on iPadOS 15–17 in the «aA» menu of the address bar), on iPhone the page menu button left of the address → Gentleman's Helper. Load the course pack, from a file or by link.
  4. A round “H” button appears on the course page: that is the helper’s panel. START starts it, STOP stops it.

To load a pack from a file, use «📤 Импорт JSON» (Import JSON) on the «📚 База вопросов» (Question database) page, which a button in the extension’s popup opens; while no pack is loaded, the popup also has «⬆️ Импортировать файл» (Import a file).

Try it on the sample course

  1. Do steps 1–2 for the site poohanoid.github.io (or allow access when Safari asks).
  2. Open the sample course: https://poohanoid.github.io/gentlemans-helper-demo/. Its first screen shows the pack link too.
  3. Open the extension’s popup, paste the sample pack’s link into the field and tap «🔗 Загрузить по ссылке» (Load from link): https://poohanoid.github.io/gentlemans-helper-demo/sample-pack.json The popup reports «Загружено: 3 вопроса, профилей: 1» (Loaded: 3 questions, profiles: 1).
  4. A round “H” button appears at the right edge of the course page (if not, reload the page).
  5. Choose «💡 Подсказки (рекомендуется)» (hints, recommended) or «🤖 Полный автомат» (fully automatic) and tap «▶️ START».
  6. The helper opens the course, answers questions 1–3 and moves past the slide; in hint mode it selects the answer and you tap Confirm. Question 4 is left out of the pack on purpose: the panel says «Нет в базе» (not in the database) — answer it yourself and the helper carries on. At the end the panel says «Курс завершён» (course completed).

The pauses are deliberate, to keep a person’s pace: by default 5 s before selecting an answer, 15–25 s before Confirm and 10–15 s before Next. They are set in «⚙️ Настройки» (Settings).

Pack format

A pack is a JSON file. The example is the sample course’s pack, in full:

{
  "format": "gentlemans-helper-pack",
  "version": "2026-09-25",
  "profiles": [
    {
      "id": "demo-v1",
      "when": ["#player.gh-demo"],
      "marker": { "selector": ".screen .counter" },
      "markerDecides": true,
      "kind": {
        "selector": ".screen .counter + .kind",
        "values": [
          { "text": "^select$", "mode": "single" },
          { "text": "^true or false$", "mode": "single" },
          { "text": "^multiple choices$", "mode": "multi" }
        ]
      },
      "question": ".screen .stem",
      "options": ".screen li.option",
      "optionText": ".text",
      "optionLabel": ".label",
      "optionChecked": ".chosen, .correct, .wrong",
      "confirm": "button.action",
      "action": {
        "selector": "button.action",
        "pending": "^confirm$",
        "ended": "^next$"
      },
      "course": {
        "selector": "header h1",
        "strip": "^Sample course:\\s*"
      }
    }
  ],
  "questions": {
    "Office fire safety": {
      "What should you do first when you discover a small fire in the office?": "Raise the alarm",
      "Fire doors may be propped open during working hours.": "False",
      "Which of these belong in a first-aid kit?": "Plasters; Sterile dressings; Disposable gloves"
    }
  }
}

Questions

  • questions — categories (usually courses) holding questions with their answers: {"Category": {"Question": "Answer"}}. A category may be split into sections: {"Category": {"Section": {"Question": "Answer"}}}.
  • An answer is a string. Several correct options are joined with “; ”. For a free-text question it is the text to write in.
  • Questions and answers are compared with the page word for word: case, punctuation and spacing do not matter, the words do. A question that only resembles a stored one is shown, and nothing is pressed.
  • On loading, the file’s answers replace stored answers to the same questions; other stored questions stay. A file holding only categories of questions, with no format or profiles, is accepted too.

Profiles

profiles describe the course pages in CSS selectors: the helper guesses nothing and works only where a profile applies. A profile with the same id replaces the stored one. Wordings are regular expressions written as strings, matched without regard to case.

  • id — the profile’s name. Required.
  • when — selectors; the profile applies only on a page where all of them are present. Required.
  • question, options — where the question text and the option rows are. Required for a player that asks questions.
  • optionText, optionLabel — the option’s text inside its row, and the label (“a”, “B.”) to drop from it.
  • optionChecked — how the page marks a chosen option; the helper reads it back to check that a choice took.
  • marker, markerDecides — the page’s own “this is a question” (selector, optionally text); with markerDecides: true a screen without it is not a question.
  • kind — where the page states the kind of question (selector) and which wordings (values[].text) map to which mode: single — one option, multi — several, scale — a scale, text — free text (its field is input, textarea by default). A kind not listed is left to you.
  • action — the question’s own button and its wordings: pending — the answer is not yet confirmed (“Confirm”), ended — it is (“Next”).
  • next — the element the page moves on with. Where it is given, the helper presses only that element, and only while the page shows it; where it is not, it looks for a button labelled next, continue, start, begin or proceed (after a Confirm of its own: next, continue, forward or proceed). A player that asks nothing (a presentation) has a profile with no question and options, and must name next.
  • confirm — the confirm button; the helper currently presses Confirm through action, and without it by label (confirm, submit, check, ok).
  • course — where the player prints the course’s name (selector) and a prefix to drop (strip); it is the category for answers taken from the course page.
  • done — the sign that a test or the course is over (selector, optionally text); the helper stops there.

Questions and answers

The “H” button does not appear

Check that the extension is on and allowed on the course’s site (“Allow” or “Always Allow”, not “Allow for One Day”); that a pack is loaded — the popup shows no warning about the pack; and that the pack’s profile describes this very player. Reload the page after granting access. On a page with no course, the popup says «⋯ Курс не найден на этой странице» (no course found on this page).

The popup says «⋯ Страница не ответила» (the page did not answer)

The “H” button is on the page, but the popup cannot reach it. Use the “H” panel, or reload the page. If that does not help, close Safari and open it again: this can happen right after the app is updated.

The panel says «Нет в базе» (not in the database)

The question is not in the pack word for word. Answer it yourself and tap Confirm; the helper carries on from there. You can add the question on the «📚 База вопросов» page («➕ Добавить вопрос», Add a question).

The panel says «Проверьте ответ» (check the answer)

The database holds a similar but different question, or the stored answer matched no option word for word. The helper shows the stored answer and presses nothing: the choice is yours.

How do the modes differ?

«💡 Подсказки» (hints): the helper selects the answer and you tap Confirm; slides, videos and the Next after an answer are its job. «🤖 Полный автомат» (automatic): it confirms and moves on by itself, graded tests included.

May I use it on my course?

That is for your course’s rules to say. Check them before you turn on automatic mode, above all on a graded test.

What does “answer from the page” mean?

One particular course player keeps the correct answers in the page itself. There the helper takes the answer from the page — also for questions the pack does not hold — and at once adds it to your database on the iPad.

What does it write into free-text questions?

The answer from the database; for a question not in it, the text set in «⚙️ Настройки» (Settings) — “No” by default. Leave that setting empty to write such answers yourself. Text already in the field is never overwritten.

A video does not start; the panel says «Ролик ждёт касания» (the clip is waiting for a tap)

Safari on iPhone and iPad plays sound only after a touch. Tap anywhere on the page and the clip starts. The helper never skips ahead in or speeds up the video on screen. So that the next clip can start without a tap, it plays a silent sound, or the previous clip muted and hidden.

The panel says «Экран возвращается — решите сами» (the screen keeps coming back)

After Next the course shows the same screen again. The helper reloads the course page once per START; if that does not help, the screen is left to you.

The panel says «Отметьте согласие сами» (tick the consent yourself)

There is a consent box next to the button. The helper never ticks such boxes.

How do I move or back up the database?

On the «📚 База вопросов» page: «📥 Экспорт JSON» (Export) and «📤 Импорт JSON» (Import); «📄 Экспорт PDF» is for reading, with a chapter per course.

Where does my data go? How do I delete everything?

Nowhere: it all stays on the device (see the privacy policy). To delete everything, delete the Gentleman's Helper app.
